## Topics Covered

- Sequential Data
- Recurrent Neural Networks (RNN)
- Hidden States
- Backpropagation Through Time
- Vanishing Gradient Problem
- Long Short-Term Memory (LSTM)
- Gated Recurrent Units (GRU)
- Applications in Natural Language Processing
- Applications in Time Series Forecasting

## Learning Objectives

By the end of this week, students will be able to:

- Explain the architecture of Recurrent Neural Networks
- Understand how sequential data is processed
- Describe the vanishing gradient problem
- Compare RNN, LSTM, and GRU architectures
- Apply recurrent neural networks to real-world problems
- Evaluate sequence-based deep learning models
