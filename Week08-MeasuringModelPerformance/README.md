# Week 8 - Measuring Model Performance

## Lecture Materials

Lecture slides and supporting materials for Week 8.

## Topics Covered

- Training Error vs Validation Error
- Bias and Variance
- Underfitting and Overfitting
- Confusion Matrix
- Precision
- Recall
- F1 Score
- ROC Curve
- Model Evaluation Metrics

## Learning Objectives

By the end of this week, students will be able to:

- Evaluate machine learning and deep learning models
- Interpret classification metrics
- Analyze model performance using confusion matrices
- Understand bias-variance tradeoffs
- Detect underfitting and overfitting
