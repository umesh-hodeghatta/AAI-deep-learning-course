# Reference Books

This page contains recommended textbooks and reference materials for the Deep Learning course.

---

## Deep Learning

**Authors:**

Ian Goodfellow, Yoshua Bengio, and Aaron Courville

**Official Book Website:**

https://www.deeplearningbook.org/

### Recommended Chapters

- Chapter 1: Introduction
- Chapter 6: Deep Feedforward Networks
- Chapter 7: Regularization
- Chapter 8: Optimization
- Chapter 9: Convolutional Networks
- Chapter 10: Sequence Modeling
- Chapter 12: Applications

### Notes

This is one of the most influential and widely cited Deep Learning textbooks.

---

## Dive Into Deep Learning (D2L)

**Authors:**

Aston Zhang, Zachary Lipton, Mu Li, and Alexander Smola

**Official Website:**

https://d2l.ai/

### Recommended Topics

- Neural Networks
- CNNs
- RNNs
- Attention Mechanisms
- Transformers

### Notes

Excellent interactive textbook with code examples and notebooks.
